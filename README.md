# 🎲 Dice Game

A fun and interactive **Dice Game** built with **React.js** and **Vite**.

This project was created to practice React fundamentals and understand how components, state, event handling, and dynamic UI updates work together in a real project.

## ✨ Features

- 🎲 Interactive dice rolling
- 🔄 Dynamic dice results
- ⚡ Fast and responsive UI
- 🎯 Game logic using React
- 🧩 Component-based architecture
- 📱 Responsive design

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## 📚 What I Practiced

While building this project, I practiced:

- React components
- `useState`
- Event handling
- Conditional rendering
- Passing data between components
- Managing dynamic UI updates
- CSS styling
- Vite project setup
